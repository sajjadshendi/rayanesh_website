# معماری رایانش

سایت با Astro و TypeScript در زمان build به HTML ایستا تبدیل می‌شود. مقاله‌ها در `src/content/articles` با Markdown، نویسندگان و شماره‌ها در مجموعه‌های JSON نگهداری می‌شوند. تنظیمات صفحهٔ نخست در `src/data/site.json` است.

## مسیر داده و انتشار

ویرایش فایل محتوا → اعتبارسنجی schema و روابط → تولید صفحات Astro → کنترل لینک‌ها و دارایی‌ها → انتشار پوشهٔ `dist` در Cloudflare Pages.

صفحه‌های مقاله، نویسنده، شماره و موضوع از داده‌ها ساخته می‌شوند. جست‌وجو فهرست JSON تولیدشده را در مرورگر می‌خواند و تفاوت حروف فارسی/عربی را همسان می‌کند. هیچ پایگاه داده یا سرویس جست‌وجوی بیرونی لازم نیست. تغییر محتوا نیازمند build تازه است.

## طراحی

زمینهٔ کاغذی، متن زغالی، سبز تیره و رنگ آجری، نشان خود رایانش و تصویر پرونده هویت سایت را می‌سازند. صفحهٔ نخست بر پرونده و انتخاب تحریریه تکیه دارد. آرشیو جلدهای ثابت دارد و صفحهٔ خواندن با فاصلهٔ سطر مناسب، فرمول و کد طراحی شده است.

CSS در `src/styles/global.css` و رفتارهای مرورگر در `src/scripts` قرار دارند. چیدمان در عرض‌های کوچک تک‌ستونی می‌شود؛ جدول و کد پیمایش مستقل دارند. فونت‌ها محلی‌اند و حرکت با تنظیم کاهش حرکت سیستم محدود می‌شود.

## حدود نسخه

پنل مدیریت اختصاصی وجود ندارد؛ افزودن محتوا از GitHub یا ابزار خط فرمان پروژه انجام می‌شود. فایل‌های اصلی PDF خارج از مخزن نگهداری شده‌اند و نسخه‌های وب در `public` هستند. برای انتقال باقی مقاله‌ها راهنمای محتوا را دنبال کنید.
